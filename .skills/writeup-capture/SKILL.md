# Writeup capture

Copy `docs/templates/SESSION-SUMMARY.md` to `docs/journal/YYYY-MM-DD-<slug>.md`.

Must capture when present:

- Schema we would redo
- Normalization maths that fought back
- Role-isolation bug (especially late)
- Feature we cut and do not regret
- Spec harder than it looked

Insight over length. See `context/examples/session-journal.md` and `plans/12-writeup-quest.md`.
